# Sweta Yadav — Portfolio

## Run locally
1. Keep all files/folders together.
2. Open `index.html` in a browser.

For the best local experience, run a simple server from this folder:
- Python: `python -m http.server 8000`
- Then open: `http://localhost:8000`

## Included
- Responsive portfolio
- User-provided profile photo
- Resume download
- Dark/light theme toggle
- Mobile navigation
- Scroll reveal animations
- Skills filtering
- Interactive project case-study modals
- LinkedIn, GitHub, email and phone links

The visual direction is inspired by the supplied reference's editorial, warm, portfolio-card aesthetic, but the layout and content are custom-built for Sweta.
